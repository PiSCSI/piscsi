# Mock PiSCSI Daemon

A lightweight mock implementation of the PiSCSI daemon for testing the web frontend without physical hardware.

## Quick Start

Build and run the mock daemon:

```shell
# Build the mock daemon
make mock

# Run it (listens on port 6868)
./mock-piscsi
```

In another terminal, start the web interface:

```shell
DISABLE_PAM=true FALLBACK_USER=test FALLBACK_PASSWORD=test ./piscsi-web
```

Then open <http://localhost:8080> in your browser.

## Features

The mock daemon responds to all major PiSCSI operations:

- **VERSION_INFO** - Returns mock version information
- **SERVER_INFO** - Returns full server configuration
- **DEVICES_INFO** - Lists attached devices (initially one mock drive)
- **DEFAULT_IMAGE_FILES_INFO** - Lists available disk images
- **DEVICE_TYPES_INFO** - Returns supported device types
- **LOG_LEVEL_INFO** - Returns log level information
- **NETWORK_INTERFACES_INFO** - Returns network interfaces
- **ATTACH** - Simulates attaching a device
- **DETACH/DETACH_ALL** - Simulates detaching devices

## Customizing Mock Data

All mock responses are generated by functions in `main.go`. To customize:

### Add More Mock Images

Edit `getMockImageFilesInfo()`:

```go
ImageFiles: []*pb.PbImageFile{
    {
        Name:     "my-custom-disk.hda",
        Type:     pb.PbDeviceType_SCHD,
        Size:     21474836480, // 20GB
        ReadOnly: false,
    },
    // Add more images here...
}
```

### Add Mock Attached Devices

Edit `getMockDevicesInfo()`:

```go
Devices: []*pb.PbDevice{
    {
        Id:         1,
        Unit:       0,
        Type:       pb.PbDeviceType_SCCD,  // CD-ROM
        Status:     "ready",
        File:       "system-cd.iso",
        Vendor:     "PiSCSI",
        Product:    "CD-ROM",
        Revision:   "1.0",
        BlockSize:  2048,
        BlockCount: 300000,
    },
    // Add more devices here...
}
```

### Change Version Info

Edit `getMockVersionInfo()`:

```go
return &pb.PbVersionInfo{
    MajorVersion: 25,
    MinorVersion: 0,
    PatchVersion: 1,
    Suffix:       "-custom",
}
```

## Protocol Details

The mock daemon implements the PiSCSI protobuf protocol:

1. Client sends: `RASCSI` (6 bytes) + size (4 bytes, LE) + protobuf message
2. Server responds: size (4 bytes, LE) + protobuf message

All operations are logged to stdout for debugging.

## Tips

- Run with `2>&1 | tee mock.log` to save logs
- The mock daemon doesn't validate requests - it always returns success
- Restart the daemon to reset all state
- You can run multiple instances on different ports by modifying the `Port` constant

## Troubleshooting

**Port already in use:**

```shell
# Find what's using port 6868
lsof -i :6868

# Or kill all piscsi processes
pkill piscsi
pkill mock-piscsi
```

**Web interface can't connect:**

- Make sure the mock daemon is running first
- Check the daemon logs for incoming connections
- Verify the web interface is configured for localhost:6868 (default)
